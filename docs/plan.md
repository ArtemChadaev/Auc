# Очень примерный план сгенерированный чтобы по бырому начать хоть чтото
# План разработки аукциона — 20 рабочих дней

На основе [init.sql](file:///Users/ima/Code/Auction/migrations/init.sql). Стек: **Go + React Router + PostgreSQL + Docker**.

---

## Неделя 1 — Инфра + Авторизация + Пользователи

| День | Что делаем | Где |
|------|-----------|-----|
| **1** | Docker-compose: добавить сервисы Go-бэка и React-фронта, авто-миграции init.sql, `.env`, healthcheck'и | `docker-compose.yaml` |
| **2** | Регистрация + логин (JWT access + refresh). Хэш пароля, создание `user_sessions` | Go |
| **3** | Refresh-токен, logout, middleware авторизации. Таблица `user_sessions` | Go |
| **4** | Профиль пользователя: GET/PATCH, soft-delete (`deleted_at`). Баланс (просмотр) | Go |
| **5** | Фронт: страницы логин/регистрация/профиль. Хранение токенов, axios interceptor | React |

---

## Неделя 2 — Items + Lots + Фронт каталога

| День | Что делаем | Где |
|------|-----------|-----|
| **6** | CRUD `items` — создание, список моих айтемов, загрузка файлов (S3/локально) | Go |
| **7** | CRUD `lots` — создать лот (draft), опубликовать (active), отменить. Валидация owner = seller | Go |
| **8** | Листинг лотов: фильтры (status, поиск), пагинация. Детальная страница лота | Go |
| **9** | Фронт: каталог лотов (список карточек), страница лота, создание лота | React |
| **10** | Фронт: страница «Мои items», загрузка файла, создание лота из item | React |

---

## Неделя 3 — Ставки + Баланс + Реалтайм

| День | Что делаем | Где |
|------|-----------|-----|
| **11** | Пополнение баланса (`ledger_entries` type=top_up). Hold/release логика | Go |
| **12** | Ставки (`bids`): сделать ставку, idempotency_key, проверка min_step, hold создание | Go |
| **13** | Завершение лота: cron/scheduler проверяет `ends_at`, winner, `hold` → captured/released, `history_item`, `ledger_entries` (payout + transfer) | Go |
| **14** | WebSocket — обновления ставок и статуса лота в реалтайме | Go |
| **15** | Фронт: форма ставки, live-обновление ставок через WS, история ставок, страница баланса + пополнение | React |

---

## Неделя 4 — Документы, полировка, деплой

| День | Что делаем | Где |
|------|-----------|-----|
| **16** | `documents` + `user_consents` — пользовательское соглашение, согласие при регистрации/ставке | Go + React |
| **17** | Обработка ошибок, валидация, rate-limiter, CORS. Логирование (`slog`) | Go |
| **18** | Фронт: адаптивная вёрстка, уведомления (toast), 404/error pages, UX полировка | React |
| **19** | Docker-compose финал: multi-stage build Go, nginx для React, volumes, networks, prod-конфиг | Docker |
| **20** | Тестирование E2E руками, баг-фиксы, README, финальная сборка `docker-compose up` и проверка всего флоу | Всё |

---

## Итого по модулям

```
users + sessions     → дни 2-5
items                → дни 6, 10
lots                 → дни 7-9
bids + hold          → дни 11-13
ledger_entries       → дни 11, 13
history_item         → день 13
documents + consents → день 16
websocket            → дни 14-15
docker               → дни 1, 19
полировка + тесты    → дни 17-18, 20
```

> [!TIP]
> Если какой-то день закончишь раньше — бери задачу следующего дня. Если затянется — можно двигать «полировку» (дни 17–18) и делать минимум.

> [!IMPORTANT]
> Самое критичное — дни 11–13 (ставки + hold + завершение лота). Это ядро аукциона, тут нужна аккуратная работа с транзакциями в PostgreSQL.
